

# **Model Management Website 👗**  

A **responsive website** designed for managing models in the fashion and entertainment industry. This platform allows agencies to showcase models, manage portfolios, and provide an interactive experience for clients.

## **Features**  

✅ **Homepage with Interactive Animations** – Stunning UI with smooth transitions  
✅ **Model Profiles** – Showcase professional models with images and bios  
✅ **Animated Marquee** – Continuous scrolling text or images  
✅ **Responsive Design** – Fully optimized for all screen sizes  
✅ **Dynamic Content** – Scroll animations using GSAP & Locomotive Scroll

## **Installation**  

### **Prerequisites**  
- A modern web browser (Chrome, Firefox, Edge)  
- A text editor (VS Code, Sublime Text, or Atom)  

### **Clone the Repository**  
```bash
git clone https://github.com/Shreshtasingh/Model_management_website.git
```
```bash
cd Model_management_website
```

---

## **Running the Project**  

### **Option 1: Open Directly in Browser**  
Simply double-click **`index.html`** to open it in a browser.  

### **Option 2: Use a Local Server (for Better Performance)**  
Using VS Code Live Server Extension:  
1. Open the project folder in VS Code.  
2. Install the **Live Server** extension.  
3. Right-click `index.html` → Click **"Open with Live Server"**.  

OR  

Using Python (for simple local hosting):  
```bash
python -m http.server 5500
```
Then, open **`http://localhost:5500`** in your browser.
